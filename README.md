# cyberchen1995/homebrew-tap

Homebrew tap for [h-guard](https://github.com/cyberchen1995/h-guard), a safety
net for agent harnesses: it blocks destructive actions, shields sensitive files,
and keeps secrets out of prompts and tool output.

[中文说明](#中文)

## Install

```sh
brew install cyberchen1995/tap/h-guard
```

This taps the repository and installs the `h-guard` cask in one step. Check the
installed version with:

```sh
h-guard version
```

Then connect h-guard to your harness; see
[Quick start](https://github.com/cyberchen1995/h-guard#quick-start).

## Upgrade and uninstall

```sh
brew upgrade h-guard
brew uninstall h-guard
```

Before uninstalling, remove h-guard's entries from your harness configuration
as described in
[Uninstall](https://github.com/cyberchen1995/h-guard#uninstall).

## Notes

- The macOS binaries are not notarized. The cask removes the
  `com.apple.quarantine` attribute after installing so that Gatekeeper lets it
  run.
- Only stable releases are published here. Release candidates are not; get them
  from [GitHub Releases](https://github.com/cyberchen1995/h-guard/releases).
- To verify a download yourself (cosign signature and SHA-256 checksums), see
  [Install](https://github.com/cyberchen1995/h-guard#install).

## How this tap is updated

`Casks/h-guard.rb` is generated by [GoReleaser](https://goreleaser.com/) from
h-guard's release workflow each time a stable version is tagged. Do not edit it
by hand; changes belong in
[`.goreleaser.yaml`](https://github.com/cyberchen1995/h-guard/blob/main/.goreleaser.yaml).
Report problems in the
[h-guard issue tracker](https://github.com/cyberchen1995/h-guard/issues).
